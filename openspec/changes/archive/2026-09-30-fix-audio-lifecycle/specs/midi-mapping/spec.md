## ADDED Requirements

### Requirement: MIDI active in every workspace view

MIDI bindings SHALL work whenever a project is open, whichever tab is active, whether the cart is open or closed, and in minimal mode. MIDI Learn SHALL work whenever its configuration UI is open.

#### Scenario: Media tab with the cart closed

- **WHEN** the operator is on the Media tab with the cart closed and presses a bound MIDI button
- **THEN** the bound action runs
